# Functional requirements

Functional requirements of the module, split by platform. The "Previous ID" column keeps the identifier they had in the per-platform specification.

## Web

| ID | Requirement | Acceptance criterion | Use case | Previous ID |
|---|---|---|---|---|
| `RF-WEB-EVT-01` | Read current catalogue events. | Listing includes PUBLISHED/SOLD_OUT with an end after the query time; drafts are not exposed to ordinary users. | [`UC-EVT-01`](use-cases/uc-evt-01-discover-events.md) | `RF-WEB-EVENT-001` |
| `RF-WEB-EVT-02` | Discover events using optional location. | Coordinates use an initial 100 km radius; no permission/position permits global browsing without blocking other features. | [`UC-EVT-01`](use-cases/uc-evt-01-discover-events.md) | `RF-WEB-EVENT-002` |
| `RF-WEB-EVT-03` | Present alternatives when none are nearby. | Discovery distinguishes nearbyEvents/otherEvents; the alternative collection is not claimed to lie within the radius. | [`UC-EVT-01`](use-cases/uc-evt-01-discover-events.md) | `RF-WEB-EVENT-003` |
| `RF-WEB-EVT-04` | Page and filter events using server criteria. | Text/type/country/region switch to global catalogue; without filters and with coordinates uses discovery pages of up to fifty. | [`UC-EVT-01`](use-cases/uc-evt-01-discover-events.md) | `RF-WEB-WEBX-005` |
| `RF-WEB-EVT-05` | Open detail and retain historically published links. | Available image, description, date, venue, organizer/contact, amount and capacity are shown; private drafts require an authorized actor. | [`UC-EVT-02`](use-cases/uc-evt-02-view-event.md) | `RF-WEB-EVENT-004` |
| `RF-WEB-EVT-06` | Open external location and contact links. | Existing map/directions, website, email or phone opens the corresponding action; missing data does not invent destinations. | [`UC-EVT-02`](use-cases/uc-evt-02-view-event.md) | `RF-WEB-EVENT-005` |
| `RF-WEB-EVT-07` | Share or report an event. | Sharing produces its public link and is only offered when the event has a public page (published at least once and not a draft); reporting identifies the event, subject to community rules. | [`UC-EVT-02`](use-cases/uc-evt-02-view-event.md) | `RF-WEB-EVENT-006` |
| `RF-WEB-EVT-08` | Request an individual or group registration. | Collects attendee count and contact (account name/email and phone); companions and notes are not requested. Configurable request limit 1–20 and registration closes no later than event start. | [`UC-EVT-03`](use-cases/uc-evt-03-register-for-event.md) | `RF-WEB-REG-001` |
| `RF-WEB-EVT-09` | Retain one active registration per user/event. | An active duplicate is rejected; owner derives from the session rather than an editable userId. | [`UC-EVT-03`](use-cases/uc-evt-03-register-for-event.md) | `RF-WEB-REG-002` |
| `RF-WEB-EVT-10` | Represent the actual registration result. | REQUESTED, WAITLISTED, AWAITING_PAYMENT, AWAITING_ATTENDEE_CONFIRMATION or CONFIRMED is not confused with automatic confirmation. | [`UC-EVT-03`](use-cases/uc-evt-03-register-for-event.md) | `RF-WEB-REG-003` |
| `RF-WEB-EVT-11` | Enforce capacity and expiry on server. | Confirmed/held seats do not exceed capacity; expiry releases holds. WAITLISTED does not advance automatically when capacity is freed. | [`UC-EVT-03`](use-cases/uc-evt-03-register-for-event.md) | `RF-WEB-REG-009` |
| `RF-WEB-EVT-12` | Separate registration and payment status. | Registration may end REJECTED/CANCELLED/EXPIRED; the page's confirmed count is not the whole event's total. | [`UC-EVT-03`](use-cases/uc-evt-03-register-for-event.md) | `RF-WEB-REG-010` |
| `RF-WEB-EVT-13` | Confirm attendance with a valid hold. | Only owner and AWAITING_ATTENDEE_CONFIRMATION convert held seats into confirmed seats; expired holds are rejected. | [`UC-EVT-04`](use-cases/uc-evt-04-confirm-attendance.md) | `RF-WEB-REG-004` |
| `RF-WEB-EVT-14` | Cancel a personal registration. | Releases seats/hold according to state; CANCELLED neither deletes the event nor issues an automatic refund. | [`UC-EVT-05`](use-cases/uc-evt-05-cancel-registration.md) | `RF-WEB-REG-006` |
| `RF-WEB-EVT-15` | View own tickets. | `/my-tickets` pages `GET /me/tickets` and `/my-tickets/:id` opens the detail by UUID; session and ownership only. | [`UC-EVT-06`](use-cases/uc-evt-06-my-tickets.md) | `RF-WEB-REG-011` |
| `RF-WEB-EVT-16` | Choose the area for nearby-event notices. | In the notification preferences, «Events near you» lets the person choose a catalogue region or remove it; it is read with `GET /users/me/event-area`, saved with `PUT /users/me/event-area` and removed with `DELETE /users/me/event-area`; the web never asks for the location. | [`UC-EVT-07`](use-cases/uc-evt-07-event-area.md) | — |
