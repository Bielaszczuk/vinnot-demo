# Testing

Test cases of the module: one for the main flow of each use case and one for each alternative flow. They can be run by hand on the web and in the app; the automated tests column shows which tests exercise the use case.

## Configurable fee

Automated tests for the fee:

- [`CommissionPolicyTest`](../../../../backend/src/test/java/com/vinnot/payment/domain/valueobject/CommissionPolicyTest.java) and [`TicketPaymentQuoteTest`](../../../../backend/src/test/java/com/vinnot/payment/domain/valueobject/TicketPaymentQuoteTest.java): the 1–3000 range, the id format, that the id matches the basis points, and the amount at 3%, 8%, 12% and 2.5% with HALF_UP rounding.
- [`ConfiguredCommissionPolicyTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/config/ConfiguredCommissionPolicyTest.java) and [`PaymentSandboxConfigurationTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/config/PaymentSandboxConfigurationTest.java): the 3% default, a configured 8%, and a startup that fails with values that disagree.
- [`PostgresCheckoutAttemptStoreTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/persistence/PostgresCheckoutAttemptStoreTest.java): an attempt stored at 3% is read back, retried and reconciled with its own fee while the current policy is 8%, and the database rejects fees that do not follow the stored policy.
- [`EventCheckoutReservationServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/EventCheckoutReservationServiceTest.java), [`MercadoPagoCheckoutAdapterTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/gateway/MercadoPagoCheckoutAdapterTest.java) and [`PaymentAccountControllerTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/web/PaymentAccountControllerTest.java): new attempts use the current policy, Mercado Pago receives the attempt's policy and fee, and the API reports the current fee.
- Web and app: `commission.test.ts`, the payment account service and hook tests, and `commissionCopy.test.ts` check that the rate comes from the API and is interpolated into the copy.

To test a rate change by hand, set `app.payments.commission.basis-points=800` and `app.payments.commission.policy=VINNOT_8_PERCENT_V1`, restart the backend, and check that `/partner/payments` shows 8% and that a new checkout sends `marketplace_fee` at 8%. An attempt created earlier keeps 3%.

## Deleted accounts

Automated tests for payment history when an account is deleted:

- [`PaymentSettlementPostgresIntegrationTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/persistence/PaymentSettlementPostgresIntegrationTest.java): the attempt's four FKs use `ON DELETE SET NULL`; deleting the buyer or the organizer works and keeps the attempt, its observation and its reconciliation job; a refund made from the panel is recorded and only the organizer is told; a payment approved after the buyer was deleted is refunded without issuing a ticket; without the organizer the job stays parked and their payment account is deleted.
- [`PostgresCheckoutAttemptStoreTest`](../../../../backend/src/test/java/com/vinnot/payment/infrastructure/persistence/PostgresCheckoutAttemptStoreTest.java): a new attempt without links is rejected and a stored one is read back without them.
- [`ApplyProviderPaymentServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/ApplyProviderPaymentServiceTest.java), [`ReconcilePaymentsServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/ReconcilePaymentsServiceTest.java), [`RequestPaymentRefundServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/RequestPaymentRefundServiceTest.java), [`DispatchTicketCheckoutServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/DispatchTicketCheckoutServiceTest.java), [`PaymentNoticeServiceTest`](../../../../backend/src/test/java/com/vinnot/payment/application/service/PaymentNoticeServiceTest.java) and [`CheckoutAttemptTest`](../../../../backend/src/test/java/com/vinnot/payment/domain/model/CheckoutAttemptTest.java): each rule for an attempt without links.

To test it by hand, buy a paid ticket with a test account, delete that account from its profile and check that the payment is still in `payment_checkout_attempts` with `buyer_id` set to `NULL`.
