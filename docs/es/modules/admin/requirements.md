# Requisitos funcionales

Requisitos funcionales del módulo, separados por plataforma. La columna «ID anterior» conserva el identificador que tenían en la especificación por plataforma.

| `RF-WEB-ADM-34` | Decidir denuncias de calidad de catálogo. | Una denuncia con motivo `CATALOG_QUALITY` muestra «Vinnot (automático)» como denunciante, el vino reconocido, el vino que eligió el miembro, la explicación localizada y enlaces a ambos vinos; se puede tomar, resolver o desestimar con una decisión, pero nunca retira el vino. | [`UC-ADM-07`](use-cases/uc-adm-07-moderate-reports.md) | — |
