# Pruebas

Casos de prueba del módulo: uno por el flujo principal de cada caso de uso y uno por cada flujo alternativo. Los de planificación, redacción, dibujo de placas, publicación, métricas y cuentas se ejecutan en el backend; los de la cola, las placas, las redes y los pilares también a mano en la web y la app.
