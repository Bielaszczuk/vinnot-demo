# Requisitos funcionales

Requisitos funcionales del módulo, separados por plataforma. La columna «ID anterior» conserva el identificador que tenían en la especificación por plataforma.

## Web

| ID | Requisito | Criterio de aceptación | Caso de uso | ID anterior |
|---|---|---|---|---|
| `RF-WEB-WIN-01` | Explorar tarjetas y total de resultados. | Se muestran nombre, bodega, tipo, imagen/fallback y valoración/reseñas disponibles; total proviene de metadata, no de contar sólo tarjetas. | [`UC-WIN-01`](use-cases/uc-win-01-search-catalog.md) | `RF-WEB-WINE-001` |
| `RF-WEB-WIN-02` | Buscar texto con debounce. | Desde dos caracteres normalizados se envía búsqueda; texto vacío/corto mantiene catálogo con filtros sin inventar resultados locales. | [`UC-WIN-01`](use-cases/uc-win-01-search-catalog.md) | `RF-WEB-WINE-002` |
| `RF-WEB-WIN-03` | Combinar filtros visibles. | Tipo, uva, país y región se combinan con texto; cambiar país limpia región y cambiar criterios reinicia paginación. | [`UC-WIN-01`](use-cases/uc-win-01-search-catalog.md) | `RF-WEB-WINE-003` |
| `RF-WEB-WIN-04` | Sugerir país a partir de ubicación autorizada. | La ubicación se resuelve contra referencias; selección manual/limpieza prevalecen y falta de permiso o coincidencia habilita exploración global. | [`UC-WIN-01`](use-cases/uc-win-01-search-catalog.md) | `RF-WEB-WINE-004` |
| `RF-WEB-WIN-05` | Limpiar búsqueda/filtros y distinguir estados. | Carga, resultado, vacío y error son estados distintos; limpiar no reinstala un país rechazado por el usuario. | [`UC-WIN-01`](use-cases/uc-win-01-search-catalog.md) | `RF-WEB-WINE-005` |
| `RF-WEB-WIN-06` | Paginar resultados del servidor. | Solicita páginas de veinte y usa hasNext/hasPrevious/totalPages; no descarga todo el catálogo para paginarlo en memoria. | [`UC-WIN-02`](use-cases/uc-win-02-page-catalog.md) | `RF-WEB-PAGE-001` |
| `RF-WEB-WIN-07` | Representar consulta en navegación web. | Lee parámetros q/search, type, grape, country, region y page; URL actualizada no garantiza restaurar todos los filtros locales. | [`UC-WIN-02`](use-cases/uc-win-02-page-catalog.md) | `RF-WEB-PAGE-002` |
| `RF-WEB-WIN-08` | Conservar presentación durante cambio de página. | La respuesta anterior puede permanecer mientras llega la nueva; no representa una segunda página confirmada ni un total nuevo antes de recibirlo. | [`UC-WIN-02`](use-cases/uc-win-02-page-catalog.md) | `RF-WEB-PAGE-003` |
| `RF-WEB-WIN-09` | Abrir detalle por identificador. | Muestra descripción, bodega/origen, uvas, alcohol, datos sensoriales y maridajes presentes; valores ausentes no se inventan. | [`UC-WIN-03`](use-cases/uc-win-03-view-wine-detail.md) | `RF-WEB-WINE-006` |
| `RF-WEB-WIN-10` | Separar información, reseñas y perfil completo. | El detalle ofrece estas vistas y acciones de comparar, compartir y agregar/abrir bodega; leer la ficha no genera IA. | [`UC-WIN-03`](use-cases/uc-win-03-view-wine-detail.md) | `RF-WEB-WINE-007` |
| `RF-WEB-WIN-11` | Mantener datos originales al mostrar resumen sensorial. | La proyección puede completar campos ausentes con perfil persistido del idioma, preservando contenido manual y scores cero. | [`UC-WIN-03`](use-cases/uc-win-03-view-wine-detail.md) | `RF-WEB-WINE-008` |
| `RF-WEB-WIN-12` | Invitar a descargar mobile para escanear. | /wines/scan muestra descarga disponible; no captura cámara, no procesa archivos y no invoca reconocimiento web. | [`UC-WIN-04`](use-cases/uc-win-04-scan-invitation.md) | `RF-WEB-WEBX-002` |
